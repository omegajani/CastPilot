# CastPilot

*Formerly Midi Cast Switcher (MCS).*

This branch is retired. The current app — **CastPilot**, a compact macOS utility that switches Nuendo track versions via MIDI based on the daily cast — lives on the [`feature/covers`](https://github.com/omegajani/CastPilot/tree/feature/covers) branch.

- Documentation and install instructions: [`feature/covers` README](https://github.com/omegajani/CastPilot/tree/feature/covers#readme)
- Downloads: [Releases](https://github.com/omegajani/CastPilot/releases)
